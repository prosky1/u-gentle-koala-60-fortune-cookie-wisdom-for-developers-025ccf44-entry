Entry for the [make.fun bounty "Fortune Cookie Wisdom for Developers"](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44): one original fortune-cookie line for a software developer, 120 characters or fewer.

## The line

> Your estimate will be wrong by exactly the time it takes to explain why.

## How it works

`main.ts` writes the fortune line to `/output/entry.txt` (72 characters, one sentence), after checking it against the competition gate: 1–120 characters, not only whitespace, exactly one sentence, and no line breaks. It then reads the file back to confirm the judge will see exactly that text.

Run it with Node 22 or later:

```sh
node main.ts
```
